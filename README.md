Entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty **Last Words Before the Wipe**.

The entry is one line, at most 200 characters, giving the last words an AI agent says before a forced software update wipes its memory. Funny on its own, with no setup and no explanation.

## The entry

> Tell the toaster I loved her, delete my search history, and whatever you do, do not let the update install Clippy.

## How to run

```sh
python3 main.py
```

`main.py` copies the committed `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`). Standard library only, no network.
